# Support

## Questions and usage help

Use the issue tracker of the repository that owns the affected component. Include the repository name, version or commit, environment, expected behavior and observed behavior.

## Bugs

Use the organization bug-report template where available. Provide reproducible steps and relevant logs with secrets removed.

## Security issues

Do not use public issues for vulnerabilities. Follow `SECURITY.md`.

## Architecture questions

For cross-project architecture, repository boundaries or design proposals, use the architecture issue template and reference any relevant ADRs in `webowie-docs/adr/`.

## Commercial or project contact

Use the official contact information published at https://webowie.com.
